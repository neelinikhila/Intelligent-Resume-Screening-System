# Intelligent Resume Screening and Candidate Matching System

## 📌 Project Overview

The Intelligent Resume Screening and Candidate Matching System is an AI-powered recruitment automation platform developed during my internship at **Blossom Air Technologies**.

The system helps HR professionals automate resume screening by extracting candidate information, calculating ATS scores, matching resumes with job descriptions, ranking candidates, generating recommendations, and sending interview emails automatically.

```bash

pip install -r requirements.txt
```

Run the application:

```bash
uvicorn main:app --reload
```
